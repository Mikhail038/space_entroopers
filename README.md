### Build
1. Clone the repo
   ```sh
   git clone https://github.com/Mikhail038/space_entroopers.git
   cd space_entroopers
   ```
2. Configure the build
   ```sh
   cmake -B build -DCMAKE_BUILD_TYPE=Debug
   ```
   **OR**
   ```sh
   cmake -B build -DCMAKE_BUILD_TYPE=Release
   ```
3. Build
   ```sh
   cmake --build build
   ```
